# คู่มือผู้ใช้ระบบจัดทำแฟ้มสะสมผลงาน

ฉบับเตรียมส่งจบ • 3 พฤศจิกายน 2569 • ตรวจเทียบโค้ดที่ `ba0f7638959f578a407632a4a2d5586de68acbfe`

คู่มือนี้อ้างอิงโค้ด ไม่ได้เปิดทดลอง UI หรือใช้บัญชีจริงในรอบเขียนเอกสารนี้ ภาพและผลบนเครื่องที่นำเสนอควรตรวจตาม [บทซ้อมนำเสนอ](LOCALHOST_DEMO_CHECKLIST.md) อีกครั้ง ไม่ถือว่าระบบทั้งหมดตรวจรับเสร็จแล้ว

## 1. เริ่มจากส่วนไหน และส่วนไหนยังต้องรอ

ระบบช่วยเก็บข้อมูลการศึกษา ผลงานและกิจกรรม และเกียรติบัตรไว้ในคลัง แล้วเลือกไปจัดเป็นพอร์ตหลายฉบับ พร้อม Preview A4 และดาวน์โหลด PDF

| ส่วน | ใช้งานตามคู่มือนี้อย่างไร |
| --- | --- |
| บัญชี คลัง Editor เทมเพลต สี และ PDF | มีเส้นทางในโค้ดปัจจุบัน ใช้เมื่อเว็บและฐานที่ผู้ดูแลเตรียมเชื่อมต่อพร้อมแล้ว การมีโค้ดไม่ใช่หลักฐานว่าบัญชีหรือทุกฐานใช้งานผ่านแล้ว |
| ทำสำเนา/ลบพอร์ต และกรอกอายุเอง | มีโค้ดและ checklist การเตรียมระบบเดิม หากไม่เห็นปุ่มหรือช่อง ให้แจ้งผู้ดูแล ไม่ติดตั้งฐานหรือเปิดการตั้งค่าเองจากคู่มือนี้ |
| Snapshot หรือฉบับข้อมูลของพอร์ต | **ยังรอติดตั้งและตรวจฐานจริง** อ่านเฉพาะหัวข้อ “หลังติดตั้งและเปิดใช้งาน” ไม่ใช้เป็นขั้นตอนสาธิตปัจจุบัน |
| การบันทึกอัตโนมัติ และการเลือกรูปย่อยแยกรายพอร์ต | ตัดออกจากโครงการ ใช้ปุ่มบันทึก และใช้รูปทั้งหมดตามลำดับของรายการ/ฉบับที่รับ |

หน้า Home `/` เปิดดูได้โดยไม่เข้าสู่ระบบ ส่วน Dashboard `/dashboard`, คลัง `/my-data` และ Editor `/editor?portfolio=…` ใช้บัญชีผู้ใช้ อย่าเดา ID พอร์ต ให้เปิดจากการ์ดของตนเอง

**ก่อนเปิด Snapshot:** พอร์ตยังใช้ข้อมูลคลังร่วม เมื่อแก้คลังแล้วเปิด/โหลดพอร์ตใหม่ ข้อมูลอาจเปลี่ยนตามคลัง ไม่ควรอธิบายว่าทำสำเนาแล้วได้คลังหรือไฟล์รูปส่วนตัวแยกทันที

## 2. สมัคร เข้าสู่ระบบ และกู้รหัสผ่าน

### สมัครและเข้าสู่ระบบ

1. ที่หน้าเข้าสู่ระบบ เลือก **สมัครสมาชิก** ไป `/register`
2. กรอก **ชื่อผู้ใช้**, **อีเมล**, **รหัสผ่าน**, **ยืนยันรหัสผ่าน** ให้ตรงกัน รหัสผ่านอย่างน้อย 6 ตัวอักษร แล้วกด **สมัครสมาชิก**
3. รอผลก่อนกดซ้ำ หากขึ้นข้อความให้ยืนยันอีเมล ให้ทำตามข้อความนั้น การตั้งค่า Auth ของสภาพแวดล้อมจริงเป็นตัวกำหนด ไม่รับรองว่าทุกฐานข้ามการยืนยันได้
4. ที่ `/login` กรอก **อีเมล** และ **รหัสผ่าน** แล้วกด **เข้าสู่ระบบ**
5. เมื่อเลิกใช้เครื่องร่วมกับผู้อื่น ให้บันทึกงานก่อน แล้วใช้ **ออกจากระบบ**

### ลืมรหัสผ่าน

1. ที่ `/login` กด **ลืมรหัสผ่าน?** กรอกอีเมลที่ `/forgot-password` แล้วกด **ส่งลิงก์ตั้งรหัสผ่านใหม่**
2. ตรวจกล่องจดหมายและจดหมายขยะ ข้อความตอบรับไม่ได้ยืนยันว่าอีเมลนั้นมีบัญชีหรือส่งถึงแล้วทุกกรณี
3. เปิดลิงก์ในเบราว์เซอร์และอุปกรณ์เดียวกับที่ขอลิงก์ เมื่อถึงหน้าตั้งรหัสผ่านใหม่ กรอก **รหัสผ่านใหม่** และ **ยืนยันรหัสผ่านใหม่** แล้วกด **บันทึกรหัสผ่านใหม่**
4. หากลิงก์หมดอายุ ใช้แล้ว หรือเปิดผิดเบราว์เซอร์ ให้กด **ขอลิงก์ใหม่** ไม่ใช้การพิมพ์ `/reset-password` เองแทนลิงก์จากอีเมล
5. ถ้ายังยืนยันการเปลี่ยนรหัสผ่านไม่ได้ ให้ลองเข้าสู่ระบบด้วยรหัสใหม่ก่อนตามข้อความหน้าเว็บ หากไม่ได้จึงขอลิงก์ใหม่ ไม่สรุปว่ารหัสเดิมยังใช้ได้แน่นอน

การรับอีเมลจริงและลิงก์กลับเว็บยังต้องตรวจในสภาพแวดล้อมนำเสนอ ไม่แสดง URL กู้รหัส รหัสผ่าน หรือข้อมูลบัญชีลงภาพรูปเล่ม

## 3. เก็บข้อมูลในคลังทั้งสามหมวด

จาก Dashboard กด **คลังข้อมูลของฉัน** แล้วเลือกแท็บ **ประวัติการศึกษา**, **ผลงานและกิจกรรม** หรือ **เกียรติบัตร**

| หมวด | ปุ่มเพิ่มและข้อมูลหลัก |
| --- | --- |
| การศึกษา | **เพิ่มประวัติการศึกษา**; กรอก **ระดับการศึกษา \*** และ **ชื่อสถานศึกษา \*** ช่องแผนการเรียน GPAX ปีเริ่ม/ปีจบ และโลโก้เป็นข้อมูลรองตามฟอร์ม |
| กิจกรรม | **เพิ่มผลงานหรือกิจกรรม**; กรอก **ชื่อผลงาน / กิจกรรม \*** รายละเอียด วันที่ หน่วยงาน/สถานที่ และรูปเป็นข้อมูลรอง |
| เกียรติบัตร | **เพิ่มเกียรติบัตร**; กรอก **ชื่อเกียรติบัตร / รางวัล \*** รายละเอียด หน่วยงานที่ออกให้ วันที่ได้รับ และรูปเป็นข้อมูลรอง |

กรอกแล้วกด **บันทึก** หากแก้รายการเดิมใช้ปุ่มแก้ไขบนการ์ด แล้วกด **บันทึกการแก้ไข** รอผลและตรวจรายการที่แสดงก่อนออกจากหน้า

### Tags

- ในฟอร์มกด **+ สร้าง Tag ใหม่** กรอก **ชื่อ Tag ใหม่** แล้วกด **เพิ่ม**
- กด Tag ที่ต้องการผูกกับรายการ กดซ้ำเพื่อเอาออกจากรายการ แล้วบันทึกรายการ ไม่จำเป็นต้องมี Tag ทุกชิ้น
- Tags เป็นของบัญชีตนเอง ไม่ใช่ข้อมูลร่วมทุกบัญชี การเอา Tag ออกจากรายการไม่ใช่คำสั่งลบ Tag ทั้งระบบ
- หากขึ้นว่า Tags โหลดไม่ครบ ให้ใช้ปุ่มลองใหม่ที่หน้าแสดง ไม่ตีความว่าไม่มี Tags และไม่ล้างสิ่งที่เลือกค้างไว้เอง

### รูปภาพ

- กิจกรรมเพิ่มได้สูงสุด **4 รูป** เกียรติบัตรเพิ่มใหม่ได้สูงสุด **2 รูป** ใช้ JPG, PNG หรือ WEBP ไม่เกิน **5MB ต่อรูป** ตามข้อความฟอร์ม
- กด **เพิ่มรูปภาพ** เลือกไฟล์ ตรวจตัวอย่าง หากเปิดกล่อง **ปรับขอบเขตรูปภาพ** เลือกสัดส่วน/ซูม/ตำแหน่ง แล้วกด **ตัดรูปและใช้รูปนี้** หรือ **ใช้รูปต้นฉบับ**; ปุ่ม **ยกเลิก** กลับไปโดยไม่ยืนยัน crop นั้น
- ตรวจรูปและลำดับที่แสดงก่อนบันทึก พอร์ตใช้รูปทั้งหมดตามลำดับคลัง/ฉบับที่รับ ไม่มีตัวเลือกรูปย่อยรายพอร์ต และคู่มือนี้ไม่ได้อ้างว่ามี drag-and-drop เรียงรูป
- เกียรติบัตรเดิมที่มีเกิน 2 รูปยังเก็บรูปครบและแก้ข้อความได้ แต่เพิ่มรูปไม่ได้จนจัดการให้เข้าเกณฑ์ การนำรูปออกเป็นการเลือกของผู้ใช้ ไม่ถูกตัดรูปทิ้งเงียบ ๆ
- **ลบรูป** เป็นการนำรูปออกจากรายการเมื่อบันทึก ไม่ใช่คำรับรองว่าลบไฟล์จาก Storage แล้ว

### ลบรายการคลัง

ขั้นตอนนี้อธิบายการใช้ปุ่ม ไม่ได้ดำเนินการลบจริงในงานเอกสาร หากซ้อมให้ใช้เฉพาะรายการสังเคราะห์ในสภาพแวดล้อมทดสอบแยกที่ผู้ดูแลยืนยัน ไม่ถือว่าเปิดผ่าน localhost แล้วปลอดจาก hosted โดยอัตโนมัติ

1. กดปุ่มลบของรายการที่ตั้งใจลบ ตรวจชื่อในกล่อง **ลบรายการจากคลัง**
2. รอรายชื่อและจำนวนพอร์ตที่ได้รับผลกระทบ ซึ่งรวมหมวดซ่อนด้วย ถ้าอ่านผลกระทบไม่สำเร็จ ให้ **ลองใหม่** หรือ **ยกเลิก** ไม่ถือว่ามีผลกระทบเป็นศูนย์
3. หากแน่ใจ กด **ลบจากคลังและทุกพอร์ต** รายการจะถูกนำออกจากพอร์ตทุกฉบับที่อ้างถึง รวมสำเนาและหมวดซ่อน หลังเปิด/โหลดข้อมูลใหม่
4. ถ้าขึ้นว่ายังยืนยันผลลบไม่ได้ กด **ตรวจสอบสถานะ** ก่อนคิดลบซ้ำ
5. การยืนยันว่าไม่มีรายการในคลังไม่ใช่หลักฐานว่าลบไฟล์ Storage ครบแล้ว งานดูแลไฟล์เป็นอีกขั้นตอนของผู้ดูแล

## 4. สร้าง เปลี่ยนชื่อ ทำสำเนา และลบพอร์ต

### สร้างและเปิดพอร์ต

ที่ Dashboard กดการ์ด **สร้าง Portfolio ใหม่** ตั้ง **ชื่อ Portfolio**, เลือกเทมเพลต แล้วกด **สร้าง Portfolio** รอให้ระบบยืนยันและเปิด Editor ชื่อที่มีแต่ช่องว่างใช้ไม่ได้

ชื่อพอร์ตเป็นชื่อสำหรับจัดการงานและตั้งชื่อไฟล์ PDF แยกจากหัวเรื่องและชื่อ–นามสกุลบนหน้าปก หากสร้างแล้วผลไม่แน่นอน ให้ตรวจรายการพอร์ตก่อนสร้างซ้ำ เพราะคำขอเดิมอาจสำเร็จแล้ว

เปิดพอร์ตเดิมจากการ์ดหรือไอคอน **แก้ไข Portfolio** ตรวจชื่อพอร์ตด้านบน Editor ให้ตรงฉบับที่จะทำงาน

### เปลี่ยนชื่อ

บนการ์ดเป้าหมายกดไอคอน **เปลี่ยนชื่อ** แก้ช่อง **ชื่อพอร์ต** แล้วกด **บันทึกชื่อ** หรือ **ยกเลิก** รอชื่อใหม่บนการ์ดหลังยืนยัน ไม่เปลี่ยนชื่อบนปกให้โดยอัตโนมัติ เปิด Editor ใหม่จึงใช้ชื่อพอร์ตที่โหลดใหม่สำหรับชื่อไฟล์ PDF

### ทำสำเนา

1. กดไอคอน **ทำสำเนาพอร์ต** ของต้นฉบับ ตรวจชื่อพอร์ตที่กล่องแสดง
2. แก้ **ชื่อพอร์ตใหม่** ซึ่งเสนอชื่อเดิมตามด้วย “สำเนา” แล้วกด **ทำสำเนา**
3. หลังยืนยัน ระบบเปิด Editor ของสำเนา ให้ตรวจชื่อพอร์ตใหม่ด้านบน สำเนามีข้อมูลรายพอร์ตให้แก้แยก เช่น เนื้อหาปก สี และการแสดงหมวด แต่ยังอ้างรายการคลังร่วม ไม่ใช่สำรองคลังหรือไฟล์รูปแยก
4. ถ้ายังไม่ทราบผล ใช้ **ตรวจสอบผล** ในกล่อง หรือ **ตรวจสอบผลคำขอค้าง** ใน Dashboard ก่อนเริ่มคำขอใหม่ หากผู้ดูแลให้ใช้ **ส่งคำขอเดิมซ้ำ** ให้ส่งคำขอเดิมที่ระบบเก็บไว้ ไม่เปิดทำสำเนารอบใหม่แทน

ระหว่างกำลังยืนยัน อย่ากดซ้ำหรือเปลี่ยนเป้าหมาย ถ้าไม่มีปุ่ม actions หรือเบราว์เซอร์ไม่รองรับกลไกทำรายการ ให้แจ้งผู้ดูแล โดยโค้ดแนะนำ Chrome หรือ Edge ไม่รับรองว่าทุกเบราว์เซอร์ผ่านการตรวจแล้ว

### ลบพอร์ต

กด **ลบพอร์ต** ของการ์ดเป้าหมาย ตรวจชื่อ และเลือก **ยกเลิก** หรือ **ลบพอร์ต** ในกล่องยืนยัน การลบพอร์ตไม่ลบรายการในคลัง ไม่ได้ยืนยันว่าลบรูปทุกไฟล์แล้ว หากไม่ทราบผลให้ตรวจคำขอค้างเช่นเดียวกับทำสำเนา ห้ามสรุปจาก network error ว่าพอร์ตยังอยู่แน่นอน

การซ้อมลบพอร์ตใช้สำเนาทดลองในระบบทดสอบแยกเท่านั้น ไม่ใช้พอร์ตงานจริง งานจัดทำคู่มือนี้ไม่ได้ลบพอร์ตใดบน hosted project

## 5. กรอกเนื้อหา เลือกรายการ และบันทึกด้วยปุ่ม

Editor มีหัวข้อพับ–ขยาย: **หน้าปก**, **คำนำ**, **ประวัติส่วนตัว**, **การศึกษา**, **ผลงานและกิจกรรม**, **เกียรติบัตร** และ **7. สีและดาวน์โหลด**

| หัวข้อ | วิธีใช้ |
| --- | --- |
| หน้าปก | กรอกหัวเรื่อง ชื่อ–นามสกุล และโรงเรียน เลือกรูปปก/ครอปตามต้องการ รูปและชื่อปกแยกจากประวัติส่วนตัว |
| คำนำ | กรอก **ข้อความคำนำ** และ **ชื่อผู้จัดทำ (ลงท้ายหน้าคำนำ)** ตรวจการขึ้นบรรทัดใน Preview |
| ประวัติส่วนตัว | กรอกข้อมูลและรูปโปรไฟล์ วันเกิดใช้คำนวณอายุ หากระบบที่เตรียมไว้มี **กรอกอายุเอง** จึงเลือกและกรอกได้ ไม่มีวันเกิดที่คำนวณได้จะแสดง “—” |
| สามหมวดจากคลัง | ติ๊ก checkbox ของรายการที่ต้องการ ดูข้อความ **เลือกแล้ว · ลำดับ …** กรองด้วย Tag หรือ **ทั้งหมด** ได้ การกรองไม่ได้ลบ selection |

ลำดับที่เลือกเป็นลำดับแสดงภายในหมวด หากต้องการจัดใหม่ในโหมดคลังร่วมปัจจุบัน ให้ยกเลิก checkbox ที่เกี่ยวข้องแล้วเลือกกลับตามลำดับที่ต้องการ ตรวจ A4 ก่อนบันทึก การเอาออกเฉพาะพอร์ตไม่ลบรายการในคลังหรือพอร์ตอื่น หลังเปิด Snapshot ต้องใช้กติกาฉบับข้อมูลในหัวข้อ 9 ไม่ใช้การเลือกใหม่เป็นวิธีรับอัปเดตเงียบ ๆ

หน้าปกใช้ **💾 บันทึกและไปหน้าถัดไป**; คำนำ โปรไฟล์ การศึกษา และกิจกรรมใช้ **บันทึกและไปหน้าถัดไป**; หมวดสุดท้ายใช้ **บันทึกเกียรติบัตร** พับหัวข้อหรือสลับไปดู Preview ไม่ใช่การบันทึก ต้องรอข้อความยืนยันก่อนถือว่าสำเร็จ

ถ้าแจ้งบันทึกล้มเหลว ให้เก็บฟอร์มไว้ อ่านข้อความและใช้การลองใหม่ที่มี อย่า refresh ขณะที่ยังมี draft หากเตือน **ข้อมูลยังไม่ได้บันทึก** ในคลัง เลือก **แก้ไขต่อ** เพื่อเก็บ draft หรือ **ทิ้งการเปลี่ยนแปลง** เมื่อยอมเสียสิ่งที่ยังไม่บันทึกจริง ๆ คำเตือน refresh/ปิดเอกสารอาจเป็นหน้าต่างของเบราว์เซอร์และไม่เหมือนกันทุกอุปกรณ์

## 6. เทมเพลตและสีรายพอร์ต

ตัวเลือก **เทมเพลต** ใน Editor ปัจจุบันคือ **Classic**, **Modern University · ฟ้า–น้ำเงิน–ขาว**, **Gallery Editorial · ภาพใหญ่–ตัวอักษรเด่น** สองชื่อหลังใช้ key ภายใน modern/minimal เดิม ไม่ต้องหาปุ่มชื่อ “Emerald Editorial” หรือ “Minimal” จากคู่มือเก่า

เลือกแล้วรอ **บันทึกเทมเพลตแล้ว** การเปลี่ยนแบบไม่ใช่การบันทึกเนื้อหา draft อื่น เมื่อบันทึกแบบไม่สำเร็จให้ตรวจแบบที่ระบบยืนยันไว้ อย่าถือว่าตัวเลือกที่คลิกถูกเก็บแล้วแน่นอน

เปิด **7. สีและดาวน์โหลด**:

1. เลือก **สีหลัก**, **สีรอง** หรือ **สีตัวอักษร**
2. ใช้จานสี ชุดสีแนะนำ หรือช่อง **รหัสสี HEX** 6 หลัก เช่น `#1D416D` แล้วดูผลใน Preview
3. สีตัวอักษรมี **ปรับสีตัวอักษรอัตโนมัติ (แนะนำ)** หากเลือกสีเองให้ตรวจความคมชัด ข้อความเตือนไม่ได้เปลี่ยนสีที่เลือกให้เองทุกกรณี
4. **ดูดสีจากหน้าจอ** ใช้ได้เฉพาะเบราว์เซอร์ที่รองรับ หากไม่มีให้ใช้จานสี/HEX แทน
5. **คืนค่าสีเริ่มต้น** คืนค่าของแบบนั้นในหน้ากรอก ต้องกด **บันทึกสีพอร์ต** เพื่อเก็บ ก่อนดาวน์โหลด PDF

Gallery Editorial คงบางองค์ประกอบเป็นสีขาว–เทาเพื่อให้อ่านชัด สีบนเว็บไซต์ไม่ได้เปลี่ยนตามสีพอร์ต และสำเนาหรือต้นฉบับต้องตรวจบันทึกสีของแต่ละพอร์ตแยกกัน

## 7. เปิด–ปิดหมวด และอ่าน Preview A4

- สวิตช์ชื่อ **แสดง…บน A4** ใช้เลือกว่าหมวดอยู่ใน Preview/PDF หรือไม่ เช่น **แสดงการศึกษาบน A4** และ **แสดงผลงานและกิจกรรมบน A4** รอข้อความยืนยันการแสดงหมวดหลังเปลี่ยน สารบัญมี control แยก
- หน้าปกแสดงเสมอ ปิดไม่ได้ ปิดหมวดอื่นไม่ลบฟอร์ม ข้อความ รูป หรือรายการที่เลือก เปิดกลับได้ การพับ Accordion อย่างเดียวไม่ปิดหมวด A4
- จำนวนหน้าบน toolbar รวมหน้าปก คำนำ และสารบัญที่แสดงจริง เลขที่พิมพ์ไม่รวมสามส่วนต้น เริ่ม 1 ที่ประวัติส่วนตัว หรือหมวดเนื้อหาแรกที่เปิดอยู่
- สารบัญสร้างชื่อหมวดและเลขเริ่มต้นอัตโนมัติ ถ้าปิดหมวดเนื้อหาทั้งหมดจะไม่สร้างสารบัญว่าง แม้เก็บความต้องการเปิดสารบัญไว้
- มือถือใช้ **กรอกข้อมูล** / **ดูตัวอย่าง** เพื่อสลับแผง ทั้งกระดาษถูกย่อให้พอดี ไม่ใช่เปลี่ยนขนาด A4 จริง
- ข้อมูลรองที่ว่างบางแถวไม่แสดงบน Profile/การ์ดสามหมวด ไม่ใช่การลบข้อมูลในฟอร์ม และไม่ควรสรุปว่าระบบซ่อนทุกหน้าว่างอัตโนมัติแล้ว

ตัวอย่างเปิดทุกส่วนและแต่ละหมวดหนึ่งหน้า: กระดาษรวม 7 หน้า แต่เลขเนื้อหาเป็น 1–4 ถ้าปิดคำนำ กระดาษเหลือ 6 หน้า โดยเลขเนื้อหาเดิมไม่เปลี่ยน

## 8. ส่งออก PDF

1. ตรวจชื่อพอร์ต รายการ ลำดับ รูป สี สารบัญ และเลขหน้า บันทึกเนื้อหาทุกหมวดและสีที่ยังค้าง
2. กด **ดาวน์โหลด PDF** แสดง progress ตามหน้าที่กำลังสร้าง ระหว่างนี้หรือรอยืนยันไฟล์ใหญ่ อย่าแก้ข้อมูล/เริ่มส่งออกซ้อน
3. ถ้าไฟล์ไม่เกินเป้าหมาย 10 MB จะดาวน์โหลดตามปกติ ไม่มีเพดานจำนวนหน้า 10 หน้า แต่จำนวนหน้ามากยังขึ้นกับทรัพยากรเบราว์เซอร์
4. ถ้าเกิน 10,000,000 bytes จะแสดง **ดาวน์โหลดไฟล์ PDF ขนาดใหญ่** พร้อมขนาดจริง เลือก **ดาวน์โหลดต่อ** เพื่อรับไฟล์ที่สร้างไว้ หรือ **ยกเลิก** เพื่อกลับไปปรับเนื้อหา ไม่ได้หมายความว่าทุกมหาวิทยาลัยจำกัด 10 MB
5. เปิดไฟล์ที่ดาวน์โหลดจริง ตรวจจำนวนหน้า ข้อความไทย รูปเต็มใบประกาศ สี และ footer ไม่ดูแค่ว่ามีไฟล์ใน Downloads

ส่งออกจากมือถือที่ซ่อน Preview ได้ตามโค้ดเดิม ไม่ต้องเปิดทุก Accordion ก่อน ปุ่มถูกบล็อกได้เมื่อข้อมูลหลักยังไม่พร้อม มี draft สีค้าง กำลังบันทึก หรือยังยืนยัน visibility ไม่ได้ ส่วน Tags โหลดล้มเหลวอย่างเดียวมีทาง retry แยก ไม่ควรตีความเป็นข้อมูลหลักหาย

หากแจ้งรูปโหลดไม่ได้/ดึงรูปไม่ได้ ให้ตรวจรูปและสิทธิ์เข้าถึงก่อนลองใหม่ หากแจ้งเนื้อหาล้น ให้ปรับรายละเอียดหรือการจัดรายการ ระบบยังไม่แบ่งการ์ดใหญ่/ข้อความยาวข้ามหน้าให้อัตโนมัติ และไม่ควรซ่อน error เพื่อบังคับส่งไฟล์

## 9. Snapshot — หลังติดตั้งและเปิดใช้งาน

**ยังไม่ใช้ในบทซ้อมปัจจุบัน** โค้ดส่วนนี้อยู่หลังการควบคุมการเปิดใช้ และยังรอชุดติดตั้ง/การตรวจเว็บกับฐานจริงตาม [ขอบเขตจบโครงการ](FINAL_DELIVERY_SCOPE.md) คู่มือนี้ไม่ให้วิธีเปิด flag และไม่อนุญาตให้ผู้ใช้เปิดเอง

เมื่อผู้ดูแลยืนยันติดตั้งและตรวจรับแล้ว พอร์ตจะเก็บฉบับข้อมูลและรูปของรายการที่รับไว้ การแก้คลังไม่ทับฉบับนั้นอัตโนมัติ รวมถึงเมื่อเปิดพอร์ตหรือสร้าง PDF ใหม่จากฉบับเดิม

### พอร์ตเก่าที่ยังไม่มีฉบับเริ่มต้น

หากพบหน้า **ฉบับข้อมูลของพอร์ต** ให้อ่านข้อความก่อนกด **ยืนยันเตรียมฉบับเริ่มต้น**: ระบบใช้ข้อมูลและรูปในคลัง ณ เวลายืนยัน ไม่ใช่กู้ข้อมูลย้อนหลังที่ไม่เคยเก็บ หากยังยืนยันผลไม่ได้ ใช้ **ตรวจสอบอีกครั้ง** หรือ **กลับ Dashboard** ไม่กดเตรียมซ้ำโดยไม่ตรวจสถานะ

### รับอัปเดตเป็นรายรายการ

1. เปิดพอร์ตที่ต้องการอัปเดต และบันทึก draft/สีที่ค้างให้เรียบร้อยก่อน
2. ในหมวดการศึกษา กิจกรรม หรือเกียรติบัตร ตรวจชื่อรายการที่แสดง **มีฉบับใหม่**
3. กด **รับอัปเดตรายการนี้** แล้วตอบยืนยันว่าจะใช้ข้อมูลและรูปฉบับใหม่แทนฉบับในพอร์ตนี้
4. ตรวจ Preview รูป ลำดับ สารบัญ และเลขหน้าอีกครั้ง การรับให้พอร์ต A ไม่เปลี่ยนพอร์ต B หรือสำเนาโดยอัตโนมัติ
5. ถ้าผลไม่แน่นอน ให้ใช้ **ตรวจสอบฉบับปัจจุบัน** ก่อนทำต่อ อย่ากด mutation ซ้ำหรือถือว่าฐานไม่ได้เปลี่ยน

รูปมากับข้อมูลทั้งชุดตามลำดับของฉบับนั้น ไม่มีเลือกรูปย่อย และไม่มีหน้ากู้คืนทุกเวอร์ชันในอดีต การทำสำเนาหลังเปิดใช้ต้องคงฉบับของต้นฉบับ ไม่รับฉบับล่าสุดจากคลังแทนเอง

**ข้อยกเว้นสำคัญ:** การลบทั้งรายการจากคลังยังต้องแจ้งผลกระทบ/ยืนยัน และนำรายการรวม snapshot ที่อ้างต้นทางออกจากทุกพอร์ตของเจ้าของ รวมสำเนาและหมวดซ่อน Snapshot ไม่ใช่ถังขยะกู้รายการที่ลบ การเอารายการออกเฉพาะพอร์ตไม่ลบคลัง และลบพอร์ตไม่ลบคลัง การลบรายการไม่ใช่การยืนยัน cleanup Storage
