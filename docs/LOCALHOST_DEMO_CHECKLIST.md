# เตรียม localhost สำหรับสาธิต — 27 ตุลาคม 2569

ใช้ checkout ของแอปที่เปิดใน VS Code และรันเว็บจริง ไม่ใช่ worktree สำหรับ Docker เพียงอย่างเดียว

## เปิดฟีเจอร์ที่ติดตั้งฐานแล้ว

1. ตรวจ `git status --short` และ branch ปัจจุบันก่อนดึง `codex/portfolio-next-phase` หากมีงานแก้ค้างให้เก็บก่อน ไม่ reset ทิ้งงาน
2. ใน `.env.local` ข้าง `package.json` คง URL/key ของ Supabase ที่ใช้อยู่ และเพิ่ม/แก้สองบรรทัดนี้ให้มีอย่างละหนึ่งบรรทัด:

```dotenv
NEXT_PUBLIC_PORTFOLIO_ACTIONS_ENABLED=true
NEXT_PUBLIC_MANUAL_AGE_ENABLED=true
```

3. หยุด dev server ด้วย Ctrl+C แล้วรัน `npm run dev` ใหม่ เปิด URL ที่ terminal แสดง ถ้าใช้ production ให้ `npm run build -- --webpack` ก่อน `npm start` เพราะ public flags ถูกฝังตอน build
4. ไม่ต้องติดตั้ง migration อายุหรือ actions ซ้ำ ทั้งสองส่วนติดตั้งบนฐานที่ตรวจแล้ว ข้อมูลนี้ไม่ใช่คำยืนยันว่าฐานอื่นถูกติดตั้งด้วย

localhost ยังต่อ Supabase ผ่านอินเทอร์เน็ต ไม่ใช่ระบบ offline และไม่ต้องเปิด Docker เพื่อใช้แอปตาม configuration นี้ Docker ใช้กับ isolated integration tests

## ซ้อมหนึ่งพอร์ตให้จบก่อนนำเสนอ

- ใช้บัญชีของตนสร้างพอร์ตทดสอบชื่อแยกจากพอร์ตงานจริง
- เพิ่มรายการคลังแต่ละหมวดพร้อมรูป เลือกรายการเข้าพอร์ตและตรวจลำดับ
- กรอกหกหมวด กดบันทึกแต่ละหมวด ลองอายุอัตโนมัติ/กรอกเอง แล้วเปิดพอร์ตใหม่เพื่อตรวจว่าคงค่า
- สลับสามเทมเพลต ตรวจสีหลัก/รอง/ตัวอักษร กดบันทึกสี
- ปิด–เปิดหมวด ตรวจสารบัญและเลขหน้า แล้วดาวน์โหลด PDF เปิดไฟล์ตรวจรูป/ข้อความจริง
- ทำสำเนา ตรวจข้อมูล สี อายุ และหมวดซ่อนของสำเนา เปลี่ยนชื่อ แล้วลบเฉพาะสำเนาทดสอบโดยยืนยันชื่อให้ถูก คลังต้องยังอยู่
- หากสาธิตลบรายการคลัง ให้ใช้รายการทดสอบเท่านั้น เพราะรายการจะถูกเอาออกทุกพอร์ตที่อ้างถึง รวมสำเนาและหมวดซ่อน
- เก็บ PDF ที่ตรวจแล้วไว้สำหรับเปิดประกอบการนำเสนอ

## ขอบเขตที่ยังต้องบอกตามจริง

รอบล่าสุดตรวจ local production + mock ผ่าน 18/18 และตรวจ metadata ฐานจริงหลัง migration แล้ว แต่ยังไม่ได้ควบคุม localhost บนเครื่องเจ้าของหรือตรวจทุกขั้นผ่านบัญชีจริง

ยังไม่ควรประกาศว่าทุกฟีเจอร์เสร็จ: ข้อความ/การ์ดยาวเกินหน้ายังมี overflow guard, cleanup ไฟล์ Storage ที่ไม่มี reference ยังไม่ครบ, และการรับอีเมลกู้รหัสจริงขึ้นกับ Auth/redirect/mail configuration ที่ต้องซ้อมจริง ระบบ autosave, เลือกรูปย่อยรายพอร์ต และ snapshot/version เป็นงานเลื่อนออกจากรอบส่งตามที่ตกลง
