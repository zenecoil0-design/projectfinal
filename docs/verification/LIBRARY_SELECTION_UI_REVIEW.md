- จำนวนที่เลือกใช้ state ปัจจุบัน ไม่สร้างสถานะบันทึกแล้วจากการเลือก
- แยก loading/load error/คลังว่าง/ยังไม่เลือก/ตัวกรองไม่พบ พร้อมปุ่มและสถานะบันทึกในธีมเดียวกับฟอร์มก่อนหน้า
- Tag และชื่อยาวตัดบรรทัด ไม่เพิ่มตัวกรอง/ค้นหา ไม่เรียงรายการใหม่
- ตรวจ logic ก่อนส่วน JSX เทียบ HEAD แล้วเหมือนเดิมทุกตัวอักษร
- lint เฉพาะ EducationForm และ regression test: 0 errors, warning เดิมเรื่อง img 1 จุด; git diff --check ผ่าน
- Chromium + mock E2E 2 ข้อผ่าน: checkbox/กดการ์ด/Space, เลือก-ยกเลิก, ลำดับ C-A-B ใน RPC และหลังโหลดกลับ, สลับหมวดรักษาข้อมูล, fail/retry save, ลิงก์คลังยังเตือนข้อมูลค้าง, loading/error/empty/filter

## ข้อจำกัดเดิมที่สังเกตได้ (ไม่ได้แก้ระบบ)

- การโหลด Tag/ความสัมพันธ์ Tag ล้มเหลวถูก console.error แล้วโหลดรายการหลักต่อ โดยไม่มี loadError ของฟอร์มในกรณีนี้ พบใน loadData ของทั้งสามฟอร์ม เป็นข้อจำกัดการรายงานข้อผิดพลาดเดิม ไม่เปลี่ยน query หรือ error logic ในงาน UI นี้
- การศึกษา/กิจกรรมบันทึกแล้วไปหมวดถัดไป ส่วนเกียรติบัตรเป็นหมวดสุดท้ายและ onNext คงอยู่ขั้นเดิม จึงต้องใช้ข้อความปุ่มตามพฤติกรรมนี้
- ทดสอบด้วย mock เท่านั้น ไม่ได้ทดสอบสิทธิ์หรือเขียนข้อมูลจริง ไม่รัน migration/reset หรือชุดทดสอบฐานข้อมูล
