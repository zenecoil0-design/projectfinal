เจ้าของเลือกให้หน้าต่อรักษาเทมเพลตทุกหน้า รวมสองคอลัมน์ Modern/Minimal ไม่เปลี่ยนเป็นคอลัมน์เดียว

## Implementation

เพิ่ม ProfilePaper วัด DOM ด้วย template/CSS/สีเดียวกันนอก Preview จึงวัดขณะมือถือซ่อน Preview ได้ วัดสำเนาของ DOM ไม่แก้ React-owned children โดยตรง แบ่งแถวแต่ละคอลัมน์แยกกันแล้วรวมเป็นจำนวนหน้ามากสุด ใช้ทะเบียน measurement เดิมก่อน export หลัง fonts/images พร้อม cleanup callbacks ตาม lifetime

แถวที่พอดีเก็บ markup เดิม แถวเดียวที่ยาวเกินหน้าใช้ splitText แบ่ง grapheme และแสดงข้อความของแถวนั้นต่อเนื่อง (รูปแบบตัวหนาภายในแถวยาวอาจไม่คงอยู่ แต่ข้อความไม่หาย) รูป/กรอบหัวหน้าเป็นส่วนประจำหน้าตามเทมเพลต ข้อมูลแต่ละแถวไม่ทำซ้ำ ไม่เปลี่ยน store, save payload, อายุ หรือ dirty baseline

Classic ซ่อนกรอบกลุ่มว่างในหน้าต่อ ตรวจขอบองค์ประกอบทั้งหน้า ไม่ใช่แค่ขอบแถว เพื่อกัน footer ล้น ใช้พื้นที่ล่างเผื่อเลขหน้า ไม่ลดขนาดฟอนต์หรือกระดาษ ไม่เปลี่ยนสูตรสารบัญ/เลขหน้า

## ขอบเขต

Backend เป็น mock, Chromium viewport emulation ไม่ใช่ hosted integration หรือโทรศัพท์จริง Portrait fixture ชุดยาวใช้ช่องรูปว่าง ไม่ใช่การพิสูจน์รูปทุกสัดส่วน/ทุกอุปกรณ์

ยังไม่ใช่ระบบจัดหน้าบรรณาธิการ: แบ่งข้อความที่ grapheme ไม่รับรอง widow/orphan แต่ละคอลัมน์อาจจบไม่พร้อมกันจึงมีช่องว่าง/หัวกลุ่มประจำหน้าที่ไม่มีแถวในบางหน้า หัวเรื่อง/ชื่อใหญ่ผิดปกติหรือเนื้อหาที่แบ่งไม่ได้ยังถูก overflow guard บล็อก ไม่รับรองข้อความยาวไม่จำกัดบนทุกเครื่อง

Education/หัวการ์ดที่ยาวมาก, Storage cleanup และตรวจอีเมลกู้รหัสจริงยังเป็นงานแยก ไม่มี migration/deploy หรือแตะข้อมูลจริง
