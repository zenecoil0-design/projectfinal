## ผลลัพธ์และขอบเขต

เดิม PaginatedSection แบ่งได้เฉพาะ description; ชื่อโรงเรียน แผนการเรียน หรือชื่อกิจกรรม/เกียรติบัตรที่ยาวเกินหน้าเต็มยังล้นได้ รอบนี้แบ่งข้อความตามลำดับ field โดยวัดการ์ดตามเทมเพลตจริง ใช้ได้กับ Classic, Modern และ Minimal

- helper `splitCardFields` เก็บอักขระครบ แบ่งที่ขอบ grapheme ภาษาไทย/emoji ไม่ตัดข้อความหรือใส่เพดานใหม่
- การ์ดสั้นใช้ markup เดิม การ์ดยาวรักษา label/value ของการศึกษา และแสดง “รายการที่ … (ต่อ)” ในส่วนต่อ
- รูปและโลโก้อยู่ในส่วนแรกเพียงครั้งเดียว หน้าต่อของ Minimal ไม่กันคอลัมน์โลโก้ที่ไม่มีแล้ว
- วัด disposable DOM clone แทนการแทนข้อความใน DOM ที่ React ดูแล; ถอด clone ใน finally
- ฟอนต์/รูปพร้อมก่อน export และการวัดซ้ำก่อน clone ใช้ registration เดิม สารบัญกับเลขหน้าคำนวณจาก Paper จริงตามเดิม
- ถ้า layout ที่ไม่ใช่ข้อความยังวางไม่ได้ คงข้อมูลเพื่อให้ overflow guard แจ้ง ไม่ตัดหรืออ้างว่าส่งออกได้ทุกกรณี
- ไม่เปลี่ยน store, draft, selection, query, บันทึก, schema, Storage, A4, renderer, คุณภาพ หรือเกณฑ์ยืนยันไฟล์ใหญ่

## PDF จริง

Fixture ใหม่มีชื่อยาว แผนการเรียน/รายละเอียด และหน่วยงาน พร้อมโลโก้หรือรูปหนึ่งใบในแต่ละหมวด ส่งออกจาก viewport 390px ที่ยังซ่อน Preview ผ่าน renderer จริง ไม่ mock PDF หรือขนาด Blob

| แบบ | Preview / PDF | Bytes |
| --- | --- | --- |
| Classic | 16 / 16 | 6,494,162 |
| Modern | 16 / 16 | 6,343,447 |
| Minimal | 18 / 18 | 6,094,921 |

อ่านไฟล์ด้วย pypdf: ทุกหน้า A4 595.28 × 841.89 pt จำนวนหน้าตรง Preview ตรวจข้อความทุก field และจำนวนรูปใน DOM; เปิดภาพจาก PDF ตรวจหน้าการศึกษาและหน้าต่อของทั้งสามแบบ รวมหน้าท้ายเกียรติบัตร ไม่พบข้อความ/ขอบ/footer ทับกันในหน้าตัวอย่างที่ตรวจ ไม่ได้ทำ OCR ยืนยันข้อความทุกหน้าใน PDF

## ข้อจำกัด

- ข้อมูล backend เป็น mock ไม่ใช่ hosted integration และ viewport ไม่ใช่โทรศัพท์จริง
- ยังไม่แบ่งกลุ่มรูปที่ใหญ่เกินหน้าเป็นหลายชุด และไม่รับรองปก/องค์ประกอบที่ไม่ใช่ข้อความขนาดใดก็ได้; overflow guard ยังอยู่
- แบ่งระดับ grapheme จึงอาจต่อคำข้ามหน้า ไม่ใช่ระบบจัดหน้าหนังสือที่มี widow/orphan control
- ไม่ได้เปลี่ยนงานค้าง Storage cleanup หรือทดสอบอีเมลกู้รหัสผ่านจริงในรอบนี้
- งานทดลองก่อนสภาพแวดล้อมถูกเริ่มใหม่ไม่ได้รวมเป็นผลตรวจของชุดส่งงาน
